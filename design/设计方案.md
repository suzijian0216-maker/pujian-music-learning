# 谱间 · 五线谱 / 钢琴 / 小提琴学习网站设计方案

> 版本 v0.1 · 2026-11-19
> 定位：单人自用、本地优先、原声乐器 + 麦克风
> 配套文件：`界面原型.html`（可直接在浏览器打开）

---

## 0. 摘要

「谱间」是一个给自己用的音乐练习室：把识谱、节奏、听音、钢琴跟练、小提琴音准训练放进同一个网站，用**短练习 + 即时反馈 + 间隔复习**把「看谱慢、找音慢、音不准、练不成系统」四个问题变成每天 10–20 分钟、可量化、可回看的数据。

产品不做课程视频、不做乐谱播放器、不强求自动给演奏打分。它只做一件事：**让你在练琴之前和练琴之中，获得以前只有老师才能给的即时反馈。**

## 1. 背景与目标

### 1.1 用户画像

| 维度 | 情况 |
|---|---|
| 水平 | 成人业余入门，同时在学钢琴与小提琴，正在学五线谱 |
| 设备 | 电脑或平板 + 原声钢琴 / 原声小提琴，用麦克风拾音 |
| 时间 | 碎片化，工作日 10–20 分钟，周末可到 1 小时 |
| 使用对象 | 只给自己用，不需要账号、不需要社交 |
| 技术偏好 | 希望打开就能用，最好断网也能练 |

### 1.2 四个真实痛点

1. **识谱反应慢**——看到音符要在大脑里「翻译」半天，位置、音名、琴键三者没有连成一条线。
2. **弹/拉得对不对，没人告诉我**——原声乐器没有 MIDI，弹错了只能靠自己听，而初学者的耳朵恰恰最不可靠。
3. **音准没有量化**——小提琴差 20 音分和差 60 音分，耳朵听不出区别，但没有数字就没有改进方向。
4. **练习不成体系**——今天练什么、上周错在哪、哪些音总认错，全靠记忆，很容易每天重复已会的、回避不会的。

### 1.3 目标与非目标

**目标**

- 把上述四个痛点各配一个明确的功能，且每个功能都能在 5 分钟内完成一次闭环；
- 所有判定结果落成本地数据，能看趋势、能复习、能导出；
- 离线可用，音频不上传，零账号零后端。

**非目标（明确不做）**

- 不做课程视频 / 直播 / 陪练老师；
- 不做原声钢琴的复音识别与整曲自动打分（技术不可靠，见 §9.3）；
- 不做社交、排行、付费、教师端；
- 不做专业制谱软件（只做 MusicXML 导入与简单标注）。

## 2. 产品定位

### 2.1 一句话

> 一个懂反馈的练习室：你看谱，它听你；你练习，它记住。

### 2.2 与现有工具的关系

| 现有方案 | 缺什么 | 谱间怎么补 |
|---|---|---|
| 识谱 App | 只练识谱，和乐器脱节 | 谱—键—音三向联动，直接落到钢琴键位 |
| 调音器 App | 只有一个表盘 | 调音器 + 长音音准曲线 + 音准历史 |
| 跟弹类 App | 依赖 MIDI 电钢 | 面向原声乐器，麦克风单音判定 |
| 乐谱播放器 | 只播放，不反馈 | 跟弹、分手、循环、录音对比 |
| 纸笔练习本 | 无法统计 | 自动记录、错题本、SRS |

### 2.3 设计原则

1. **一次练习一个页面完成**，不跳来跳去，减少启动摩擦。
2. **反馈即时但克制**：给正确率、偏差、趋势，不给排名和总分红黑榜，避免打击兴趣。
3. **本地优先**：IndexedDB 存储，一键导出 JSON 备份；音频只在本机处理。
4. **键盘优先、触屏友好**：电脑上全键盘可操作，平板上大按钮、横屏双栏。
5. **内容可生成**：练习由算法生成，不依赖一次性录入大量曲谱；曲库只做点缀。

## 3. 典型使用场景

- **早晨 5 分钟**：识谱闪卡 20 题，看正确率与反应时间。
- **晚上 20 分钟**：钢琴单音跟弹 10 分钟 → 小提琴长音音准 5 分钟 → 节拍器节奏 5 分钟。
- **周末 40 分钟**：视奏限时训练 + 一首新曲分句练习 + 录音回放对比。
- **出差/旅行**：PWA 离线打开识谱与节拍器，无需网络。

## 4. 学习闭环与教学法

```
看谱  →  想音  →  发声（弹/拉/唱）  →  系统听  →  即时反馈  →  记录  →  明日复习
 ↑                                                                          │
 └────────────────────────── 间隔重复调度 ←─────────────────────────────────┘
```

| 教学法 | 在站内的体现 |
|---|---|
| 主动回忆 | 速认、模唱、听写：先自己想，再看答案 |
| 间隔重复 | 每个知识点是卡片，按 SM-2 简化调度（§9.5） |
| 交错练习 | 每日任务混合识谱、节奏、音准，不长时间练单一类型 |
| 即时反馈 | 对/错/偏高偏低多少音分，300ms 内给出 |
| 难度阶梯 | 每类练习分 Level 1–10，通过率达标才解锁下一级 |
| 刻意练习 | 错题自动进入「薄弱点」，优先出现在下一次任务里 |

## 6. 模块详解

### 6.1 识谱训练

**目标**：把「看到音符 → 说出音名 / 按下琴键」的路径练到条件反射。

**三种练习形态**

1. **音符速认（主）**：谱面出 1 个音 → 4 个音名选项（或虚拟键盘作答）→ 即时判定 → 自动下一题。记录每题反应时间，超过 5 秒算放弃并记为错误。
2. **谱键联动**：谱面出 1 个音 → 在虚拟键盘上按出来。点错时高亮正确键并显示音名，建立「位置↔键位」映射。
3. **节奏拍击**：谱面出 1–2 小节节奏 → 跟随节拍器按空格/点击，比较落点与目标节奏的偏差（±120ms 内为正确）。

**难度分级**

| Level | 内容 | 通过条件 |
|---|---|---|
| L1 | 高音谱号，C4–C5，仅四分音符 | 20 题 ≥ 80% |
| L2 | 高音谱号，C4–C6，含加线 | ≥ 80% 且平均反应 < 3.5s |
| L3 | 低音谱号，C3–C4 | ≥ 80% |
| L4 | 大谱表随机高/低音 | ≥ 80% |
| L5 | 调号（1–3 个升降号）与临时记号 | ≥ 75% |
| L6+ | 混合、限时、双音 | — |

**界面要素**：谱面区（大、居中）、答题区（4 个大按钮 / 键盘）、状态条（正确率、题数、连对、平均反应）、结束页（正确率、错题列表、是否升级）。

**记录数据**：`SkillCard`（音名 + 谱号 + 调号）、每题 `correct`、`rtMs`、`cents`（跟弹时）。

**文案示例**

- 正确：`✓ E5 · 1.2s`
- 错误：`✗ 是 E5，不是 F5 —— 在第四线上`
- 超时：`⏱ 超时了，答案是 A4（第二间）`

### 6.2 乐理与听音

- **音程听辨**：播放两个音，选择大二度/小三度/纯五度等；先固定根音，后随机根音。
- **和弦听辨**：大三/小三/减三/增三，原位；进阶转位。
- **旋律模唱**：播放 3–5 个音，用虚拟键盘复现。
- **节奏听写**：播放短节奏型，点击时值填入。

判定与识谱一致：正确率 + 反应时间；错题进 SRS。

### 6.3 钢琴

**核心约束**：原声钢琴用麦克风拾音，**复音检测不可靠**。因此所有跟弹功能都基于「单音、分离、可检测的起音」，这是产品边界，也是可靠性的来源。

**单音跟弹流程**

1. 谱面显示一个音（含指法提示）→
2. 你弹下 → 系统检测起音与基频 →
3. 300ms 内反馈：✓ 正确 / ✗ 音高不对（你是 D5，应为 E5）/ ↑ 偏高 32 音分 →
4. 自动进入下一音，或点击「再听一次」。

**分手 / 分段循环**

- 选择右手 / 左手 / 双手；
- 选择 2–4 小节，循环播放高亮，逐音判定；
- 循环次数、速度（50%–100%）可调。

**电脑键盘弹奏（无需 MIDI / 电钢）**

目标：没有 MIDI 键盘时，也能"敲键盘就像弹琴"——这是原声钢琴用户最直接的输入方式，也是跟弹练习的备用输入。

**键位怎么排才顺手？** 钢琴的音高是"从左到右"，电脑键盘却只有两排字母键，这是根本矛盾。两种可行排法：

**方案 A：双手分区（默认）**——音高沿 Home 排从左到右递增，两只手物理上左右分开。

| 手 | 白键 | 白键音 | 黑键 | 黑键音 |
|---|---|---|---|---|
| 左手 | `A` `S` `D` `F` `G` | C5 D5 E5 F5 G5 | `W` `E` `T` `Y` | C#5 D#5 F#5 G#5 |
| 右手 | `H` `J` `K` `L` `;` | A5 B5 C6 D6 E6 | `U` `O` `P` | A#5 C#6 D#6 |

音域 C5–E6。优点：符合钢琴"音越高越往右"的空间直觉；左右手各管一段，不打架；黑键都在上一排，食指/中指自然够到；与 Ableton / Logic 等 DAW 的电脑键盘布局一致。缺点：只有 1 个八度 + 大三度。

**方案 B：双排两八度（可选）**——下排低八度，上排高八度。

| 排 | 白键 | 黑键 | 音域 |
|---|---|---|---|
| 下排 | `Z` `X` `C` `V` `B` `N` `M` | `S` `D` `G` `H` `J` | C5–B5 |
| 上排 | `Q` `W` `E` `R` `T` `Y` `U` | `2` `3` `5` `6` `7` | C6–B6 |

音域 C5–B6。优点是音域大；但它有三个硬伤，所以不作为默认：

1. **右手分到的音太少**：每个八度右手只有 A、B 两个白键（`N` `M` / `Y` `U`），旋律跑动主要落在左手，和"右手弹旋律"的习惯相反；
2. **上排黑键要够数字排**（`2` `3` `5` `6` `7`），比下排的 `S` `D` `G` `H` `J` 费力，两个八度难度不对称；
3. **音高是往上翻八度，不是往右走**，和真琴的横向空间感不一致。

结论：默认双手分区；需要更大音域时一键切到双排两八度。范围小的补偿是 `[` `]` 移八度，以及后续"自动跳到目标音所在八度"。

- **手感关键**：`keydown` 起音、`keyup` 释放，而不是点一下播固定时长——按住能延续、松开立即止音，才像琴。
- **按键识别用 `e.code`**（`KeyZ`、`Digit2`），不用 `e.key`：中文输入法、大写锁定、不同键盘布局都不会打乱映射。
- **复音**：最多 10 个音同时；忽略系统自动重复（`e.repeat`）；切换页面或窗口失焦时全部释放，避免"卡音"。
- **移八度**：`[` `]` 整体上/下移一个八度（C3–B7 范围内），屏幕键盘与键位标签同步重建。
- **两种模式**：`跟弹`（判对错、自动进下一音）与 `自由弹奏`（不判分，纯弹）。
- **视觉**：每个琴键标出对应的电脑键；按下时高亮；顶部常驻显示当前音域与键位方案。
- **不冲突**：键盘映射只在钢琴页生效，不占用空格（节拍器）与 `1–4`（识谱答题）。
- **音色**：4 个谐波 + 低通滤波 + 衰减包络实时合成；正式版可替换为采样钢琴（如 Salamander），手感更真。
- **边界**：电脑键盘没有力度与踏板，按固定力度触发；需要力度时再走 MIDI / 麦克风。

**曲库**

- 内置公版曲按难度 1–5 分级（完整清单见 §10），练习版只取主题段、单声部；
- MusicXML 导入，OSMD 渲染；导入的曲目只存本地，不随站点分发；
- 简谱/五线谱切换（简谱仅展示，不作为判定依据）；
- 每首曲可标注指法、难点小节。

**视奏训练**

- 从生成器或曲库随机抽 4 小节；
- 限时 60 秒，记录「每分钟正确音数（CPM）」；
- 结束后对比历史，显示进步曲线。

**评分模型（保守）**

只对单声部、慢速、起音清晰的片段计算。三个维度，不合成总分：

- 音准：命中音占比（允许 ±50 音分）
- 节奏：起音时间偏差的中位数（目标 ±120ms）
- 完整度：检测到的音数 / 目标音数

### 6.4 小提琴

**调音器**

- 空弦 G3 / D4 / A4 / E5；
- 表盘显示当前音名、频率、音分偏差；±5 音分内变绿；
- A4 基准 440 / 442 可切换；
- 麦克风权限被拒时，降级为「参考音播放」模式。

**长音音准曲线**

- 选目标音（空弦或音阶音）→ 拉长音 4–10 秒；
- 实时画「音分偏差—时间」曲线；
- 评分：平均绝对偏差、波动范围、稳定在 ±10 音分内的时长占比。

**单音音准判定**

- 谱面给音 + 指板位置提示 → 拉 → 判定偏高/偏低多少音分；
- 连续 3 个音正确则进入下一组；
- 错误提示结合指板图：「A 弦 第二指，偏高 25 音分，手指往琴头方向一点」。

**指板图 / 把位**

- 四弦横置，显示 1–4 把位音名与半音位置；
- 点击音名播放参考音；
- 与谱面音联动高亮。

**音阶 / 琶音**

- 选择调性与把位，生成音阶；
- 逐音校验，结束后显示每个音的偏差分布（热力条）。

### 6.5 通用工具

**节拍器**：40–208 BPM，2/3/4/6 拍，细分（四分/八分/三连音），重音，视觉摆锤，tap tempo，±5 BPM 渐快练习。

**录音机**：麦克风录音，波形显示，AB 循环，0.5×–1× 变速不变调（后期）。

**曲库**：按乐器/难度/标签筛选，收藏，最近练习。

**设置**：A4 基准、音名体系、默认谱号、麦克风设备与灵敏度、主题（浅色/深色）、数据导出/导入/清空。

### 6.6 进度与激励

- **技能树**：识谱、节奏、钢琴、小提琴四条线，各 Level 1–10；节点显示掌握度环。
- **掌握度**：`0.6 × 正确率 + 0.4 × 反应时间得分`，滑动平均。
- **SRS 队列**：每天到期卡片 ≤ 30 张，优先薄弱点。
- **每日任务**：3 个，各 3–8 分钟，混合领域；完成后打卡。
- **周报**：练习时长、正确率趋势、音准分布、最弱 3 个点。
- **成就**：克制，只保留「连续 7 天」「音准 ±10 音分保持 20 秒」「视奏 40 CPM」这类过程型成就，不做排名。

### 8.2 反馈文案规范

- 正确：绿色 + `✓` + 「E5 · 1.2s」，不弹窗。
- 错误：红色 + `✗` + 「是 E5（第四线），不是 F5」，不扣分式惩罚。
- 检测不到：黄色 + 「没听清，再弹一次」——**不判错**，避免环境噪声造成误判。
- 音准：`偏高 23 音分` / `偏低 8 音分`，同时给方向提示。

### 8.3 错误与降级

| 情况 | 处理 |
|---|---|
| 麦克风权限被拒 | 引导说明 + 「不使用麦克风」降级为看谱点击模式 |
| 没有可用麦克风 | 检测设备列表，提示插入或换浏览器 |
| 环境噪声过大 | 提示安静环境 / 检测灵敏度调节 / 「没听清」不判错 |
| 浏览器自动播放限制 | 首次交互后解锁 AudioContext |
| 录音中断 / 页面隐藏 | 暂停并保存已完成数据 |
| 数据丢失 | 每周提示导出备份；导入时校验版本 |
| 平板/手机无键盘 | 触屏点击作答，隐藏快捷键提示 |

## 9. 技术方案

### 9.1 架构

```
┌─────────────────────────────────────────────┐
│  React + TypeScript + Vite（纯静态 SPA）     │
│  ├─ 页面/路由（React Router）                │
│  ├─ 状态（Zustand）                          │
│  ├─ 谱面（VexFlow 生成 / OSMD 渲染 MusicXML）│
│  ├─ 音频（Tone.js + Web Audio + pitchy）     │
│  └─ 存储（Dexie / IndexedDB）                │
├─────────────────────────────────────────────┤
│  PWA（离线缓存，可安装）                      │
│  部署：Cloudflare Pages / Vercel / 本地静态   │
└─────────────────────────────────────────────┘
无后端。音频只在浏览器内处理，不上传。
```

### 9.2 选型

| 层 | 选择 | 理由 |
|---|---|---|
| 框架 | React 18 + TypeScript + Vite | 生态成熟、构建快、类型安全 |
| 样式 | Tailwind CSS | 快速搭 UI、一致的设计 token |
| 状态 | Zustand | 轻量，跨页面共享练习会话 |
| 谱面（练习） | VexFlow | 程序化生成练习谱最方便 |
| 谱面（曲库） | OpenSheetMusicDisplay | MusicXML 渲染规范、支持光标跟随 |
| 音频合成 | Tone.js | 钢琴音色、节拍器调度、时间轴 |
| 音高检测 | pitchy（McLeod Pitch Method） | 体积小、单音准、浏览器可用 |
| 存储 | Dexie / IndexedDB | 结构化查询、容量大、可导出 |
| 离线 | vite-plugin-pwa | 缓存壳与资源，断网可用 |
| 测试 | Vitest + Playwright | 判定逻辑单测 + 关键流程冒烟 |

**备选**：音高检测可换 aubio-wasm（YIN，抗噪略好但体积大）或 CREPE（最准但需 TensorFlow.js，较重）。先用 pitchy，效果不够再换。

### 9.3 音高检测与判定

```
getUserMedia
  → AudioContext（关闭回声消除/降噪/自动增益，保证音高准确）
  → AnalyserNode（fftSize 2048 / 4096）
  → pitchy 检测基频 + clarity
  → 置信度过滤（clarity < 0.8 丢弃）
  → 中值滤波（5 帧）
  → 音名 + 音分偏差
```

- 检测范围：60–2000 Hz；`cents = 1200 × log2(f / f_target)`。
- 起音检测：能量包络上升 + 谱通量峰值；判定「是否发声」和「何时发声」。
- **单音可靠，复音不做**：这是产品边界，也是练习设计的依据（一次一个音、音之间留间隔）。
- 端到端目标延迟 < 300ms（含检测窗口）。

### 9.4 评分

- 目标音序列 vs 检测音序列做 DTW 对齐；
- 匹配条件：`|音分偏差| ≤ 50` 且 `|起音时差| ≤ 120ms`；
- 输出：音准命中率、节奏偏差中位数、完整度；
- 展示：三个数字 + 趋势，不合成总分，不做红黑榜。

### 9.5 间隔重复（SM-2 简化）

- 新卡片：`interval = 0`，立即到期；
- 答对：`1 → 3 → 7 → 16 → 35` 天，`ease ± 0.1`；
- 答错：`interval = 1`，明天再来，`ease - 0.2`（下限 1.3）；
- 反应时间明显变慢（> 2× 历史均值）视作「勉强答对」，间隔不升级。

### 9.6 数据模型

  stats: { total: number; correct: number; avgRtMs: number; lastSeenAt: number };

### 9.7 存储、备份与性能

- IndexedDB 三张表：`cards`、`sessions`、`pieces`，设置存 `localStorage`；

## 12. 风险、边界与决策记录

| 风险 / 决策 | 说明 | 应对 |
|---|---|---|
| 原声钢琴复音识别不可靠 | 多泛音、多音重叠导致检测失败 | 只做单音/单声部；练习设计保证音间有间隔 |
| 环境噪声与混响 | 误判为「音不准」 | 置信度过滤 + 「没听清」不判错 + 灵敏度调节 |
| 麦克风延迟与设备差异 | 不同设备延迟不同 | 校准流程；判定用相对时间而非绝对延迟 |
| 浏览器自动播放限制 | 首次无声 | 首次点击时解锁 AudioContext |
| Safari 兼容 | Web Audio/PWA 行为差异 | 以 Chromium 为主，Safari 做降级 |
| 版权 | 曲谱侵权风险 | 只用公版与自编 |
| 打分过严打击积极性 | 初学者容易受挫 | 分数克制、以趋势为主、错误不惩罚 |
| 功能贪多 | 做不完 | 严格 P0/P1/P2，M1 先可用 |
| 电脑键盘没有力度/踏板 | 手感与真琴有差距 | 固定力度 + 衰减包络；需要力度时走 MIDI / 麦克风 |
| 数据丢失 | IndexedDB 被清理 | 每周提醒导出 JSON |

**已定决策**

1. 纯前端、无账号、无后端 —— 与「只给自己用」一致，隐私最好、维护成本最低。
2. 不做复音识别 —— 技术边界内保证可靠，而不是做看起来强大但经常出错的功能。
3. 练习内容算法生成 + 少量公版曲 —— 避免曲谱版权与录入成本。
4. 用「正确率 + 趋势 + 偏差」代替总分排名 —— 保护学习动机。

### 14.2 术语

- **音分（cent）**：1 个半音 = 100 音分，用于表示音高偏差。

- **SRS**：间隔重复系统（Spaced Repetition System）。
- **DTW**：动态时间规整，用于对齐两段有速度差异的音符序列。
- **MusicXML**：通用的乐谱交换格式。
